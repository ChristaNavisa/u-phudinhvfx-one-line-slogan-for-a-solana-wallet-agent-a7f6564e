One slogan, one line, for a Solana wallet agent:

> Your money goes out. Your wallet does the worrying.

Nine words, fifty-one characters. The money leaves, the wallet carries the worry — a wallet agent that handles the details so its human doesn't have to. Plain words, no jargon: a newcomer reads it once and gets the promise.
